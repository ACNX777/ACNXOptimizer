# ACNX+ OPTIMIZER v2.0

Versi **berwarna** (Oneclick Style) dengan dukungan **Wi-Fi + Ethernet**. **100% offline** — tanpa download tool tambahan.

## ✨ Yang baru di v2.0

- 🎨 **Tampilan berwarna** ANSI (ungu, hijau, kuning, cyan) + emoji + banner.
- 🌐 **Network Tweaks** berlaku untuk **Ethernet (IfType 6) DAN Wi-Fi (IfType 71)** — bukan ethernet-only.
- 🔌 Menu **Aktifkan Wi-Fi + Ethernet** (semua adapter fisik jadi ON).
- 🖥️ Submenu **GPU: NVIDIA / AMD / Intel** + detail lengkap semua GPU.
- 💾 Opsi **System Restore Point** + **backup Registry** sebelum tweak.
- 📴 **100% offline**, tidak butuh internet.

## ▶️ Cara pakai

1. Download `ACNX-Optimizer-v2.0.zip` lalu **Extract**.
2. Klik 2× **`ACNX777+ OPTIMIZER.bat`**.
3. Saat muncul **UAC** → klik **Yes**.
4. Pilih menu (angka).

## 🧰 Persyaratan

- Windows 10 / Windows 11
- Hak Administrator
- Tidak butuh internet

## ⚠️ Peringatan

Script ini mengubah registry, service Windows, dan konfigurasi jaringan.
Gunakan **dengan risiko sendiri**. **Buat Restore Point dulu** (opsi tersedia di dalam script).
Software disediakan **"AS IS"** tanpa jaminan apa pun — lihat LICENSE.
