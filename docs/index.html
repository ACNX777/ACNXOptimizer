ACNX Optimizer

Optimizer PC / Laptop Windows — gratis, offline, tanpa install program tambahan.

ACNX Optimizer (nama file: ACNX777+ OPTIMIZER.bat) adalah script optimizer Windows untuk mengoptimalkan performa PC dan laptop. Semua fitur memakai tool bawaan Windows: powercfg, netsh, reg, sc, defrag, dan PowerShell. Tidak butuh internet sama sekali.

⚠ Penting: script ini mengubah registry, service, dan jaringan Windows sebagai Administrator. 100% offline bukan berarti 100% aman. Baca Risiko & Keamanan sebelum menjalankannya.

⬇ Download ACNX Optimizer v2.1 Lihat di GitHub

Fitur ACNX Optimizer

  • Diagnostik Sistem — info OS, CPU, RAM, GPU, disk, dan adapter jaringan.
  • System Tweaks — efek visual, GPU Scheduling, matikan telemetry, GameDVR, Storage Sense, mouse acceleration.
  • Network Tweaks — berlaku untuk Ethernet (IfType 6) dan Wi-Fi (IfType 71), DNS + TCP, disable Nagle, reset jaringan.
  • GPU Tweaking — NVIDIA (power limit, clock lock), AMD, Intel.
  • Services Tweaks — telemetry, SysMain, Windows Search, layanan Xbox.
  • Disk & RAM Cleanup — Disk Cleanup, defrag, Temp/Prefetch/Update cache, trim working set.
  • Power Plan — High / Balanced / Power Saver / Ultimate Performance.
  • Maintenance — Restore Point, SFC, DISM, CHKDSK, reset Windows Update.
  • Restore Defaults — undo semua tweak.
  • Keamanan & Risiko — halaman penjelasan risiko di dalam script (menu [10]).

Cara pakai

  1. Download ACNX-Optimizer-v2.1.zip dari halaman Releases.
  2. Extract ZIP-nya.
  3. Klik 2x ACNX777+ OPTIMIZER.bat.
  4. Saat muncul UAC, klik Yes.
  5. Baca layar peringatan risiko, ketik Y kalau sudah paham (N untuk keluar).
  6. Buat Restore Point di layar Persiapan (sangat disarankan).
  7. Pilih menu (angka).

Persyaratan

  • Windows 10 / Windows 11 (64-bit disarankan)
  • Hak Administrator
  • Tidak butuh internet

⚠ Risiko & Keamanan

Script ini mengubah registry, service Windows, dan konfigurasi jaringan dengan hak Administrator. Karena itu tidak ada script optimizer yang bisa disebut “100% aman” — termasuk yang ini. Yang 100% di sini hanya sifat offline-nya: script tidak mengunduh apa pun dari internet.

Risiko utama

MenuTindakanRisiko nyata
[3] Reset Jaringannetsh winsock reset, netsh int ip reset, ipv4/ipv6 resetSeluruh stack jaringan kembali ke default. VPN, DNS custom, IP statis, dan proxy bisa hilang. Wajib reboot. Sesekali Wi-Fi perlu di-setup ulang.
[5] Services TweaksMenonaktifkan DiagTrack, dmwappushservice, Fax, SysMain, WSearch, layanan XboxPermanen sampai di-restore. Windows Search mati → pencarian lambat. SysMain mati → buka aplikasi lebih lambat. Layanan Xbox mati → game Microsoft Store bisa tidak jalan.
[6] Hapus Temp/Prefetchdel /f /s /q dan rd /s /q di Temp, Prefetch, cache Windows UpdateTidak bisa dikembalikan. Tanpa Prefetch, aplikasi pertama kali dibuka lebih lambat. Cache update dihapus → update harus diunduh ulang.
[4] GPU Tweakingnvidia-smi -pl (power limit), nvidia-smi -lgc (clock lock)Power limit turun relatif aman. Clock lock bisa membuat driver crash / black screen / reboot kalau nilainya salah.
[2] System TweaksHAGS, NetworkThrottlingIndex off, telemetry offDi sebagian driver/game HAGS justru bikin stutter. Network throttling off bisa bikin jaringan kurang stabil. Matikan telemetry bisa bertentangan dengan kebijakan kantor/sekolah.

Yang TIDAK dilakukan script

  • Tidak menyentuh boot (tidak ada bcdedit / bootsect)
  • Tidak memformat atau menghapus partisi
  • Tidak menghapus service (tidak ada sc delete) — hanya menonaktifkan
  • Tidak mematikan Windows Defender atau firewall
  • Tidak mematikan IPv6 (Wi-Fi tetap normal)
  • Tidak mengirim data ke internet (100% offline)

Pengaman yang tersedia

  • Restore Point otomatis (layar Persiapan atau menu [8])
  • Backup registry HKLM + HKCU → C:\Optimizer Backup\Registry
  • Backup registry adapter → C:\Optimizer Backup\Network
  • Menu [9] Restore Defaults untuk membatalkan semua tweak
  • Konfirmasi Y/N sebelum tindakan berbahaya

Catatan: Restore Point hanya berisi registry dan file sistem — bukan data pribadi Anda. Kalau System Protection sedang mati, restore point bisa gagal dibuat.

🦠 Antivirus & SmartScreen

File .bat yang mengubah registry memang sering dicurigai antivirus atau diblokir Windows SmartScreen. Pada script ini umumnya false positive, karena sumbernya terbuka (MIT), 100% offline, dan hanya memakai tool bawaan Windows.

Unduh hanya dari halaman resmi: github.com/ACNX777/ACNXOptimizer/releases/latest

Cara pakai paling aman

  1. Buat Restore Point dulu (layar Persiapan).
  2. Tes di VM (VirtualBox / VMware) kalau memungkinkan.
  3. Jangan jalankan semua menu sekaligus — satu per satu, lalu reboot.
  4. Kalau Anda tidak nyaman dengan risikonya: jangan jalankan.
