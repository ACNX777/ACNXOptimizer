ACNX Optimizer

Optimizer PC / Laptop Windows — gratis, offline, tanpa install program tambahan.

ACNX Optimizer (nama file: ACNX777+ OPTIMIZER.bat) adalah script optimizer Windows untuk mengoptimalkan performa PC dan laptop. Semua fitur memakai tool bawaan Windows: powercfg, netsh, reg, sc, defrag, dan PowerShell. Tidak butuh internet sama sekali.

⬇ Download ACNX Optimizer v2.0 Lihat di GitHub

Fitur ACNX Optimizer

  • Diagnostik Sistem — info OS, CPU, RAM, GPU, disk, dan adapter jaringan.
  • System Tweaks — efek visual, GPU Scheduling, matikan telemetry, GameDVR, Storage Sense, mouse acceleration.
  • Network Tweaks — berlaku untuk Ethernet (IfType 6) dan Wi-Fi (IfType 71), DNS + TCP, disable Nagle, reset jaringan.
  • GPU Tweaking — NVIDIA (power limit, clock lock), AMD, Intel.
  • Services Tweaks — telemetry, SysMain, Windows Search, layanan Xbox.
  • Disk & RAM Cleanup — Disk Cleanup, defrag, Temp/Prefetch/Update cache, trim working set.
  • Power Plan — High / Balanced / Power Saver / Ultimate Performance.
  • Maintenance — Restore Point, SFC, DISM, CHKDSK, reset Windows Update.
  • Restore Defaults — undo semua tweak.

Cara pakai

  1. Download ACNX-Optimizer-v2.0.zip dari halaman Releases.
  2. Extract ZIP-nya.
  3. Klik 2x ACNX777+ OPTIMIZER.bat.
  4. Saat muncul UAC, klik Yes.
  5. Pilih menu (angka).

Persyaratan

  • Windows 10 / Windows 11 (64-bit disarankan)
  • Hak Administrator
  • Tidak butuh internet
⚠ Peringatan

ACNX Optimizer mengubah registry, service Windows, dan konfigurasi jaringan. Gunakan dengan risiko Anda sendiri. Buat Restore Point terlebih dahulu (opsi tersedia di dalam script). Software disediakan "AS IS" tanpa jaminan apa pun — lihat lisensi MIT.
